This project uses an Arduino Uno and an HC-SR04 Ultrasonic Sensor to measure the distance of an object. It also uses a red LED as a warning indicator when an object gets too close to the sensor.

The ultrasonic sensor sends out sound waves that cannot be heard by humans. When these sound waves hit an object, they bounce back to the sensor as an echo.

The Arduino measures how long it takes for the sound waves to return and uses that time to calculate the distance of the object.
